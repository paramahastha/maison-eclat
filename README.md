# Maison Éclat

Maison Éclat is a planned immersive website for a fictional independent fragrance house. The concept explores editorial storytelling, interactive fragrance discovery, and cinematic motion.

The project is in the planning stage; the website has not yet been implemented. See [the master build plan](CODEX_LUXURY_MOTION_MASTER_PLAN.md) for the vision, scope, and implementation requirements.

## Spec Kit

This repository is initialized with [GitHub Spec Kit](https://github.com/github/spec-kit) and its Codex integration. Open the project in Codex and use `$speckit-constitution` to establish project principles or `$speckit-specify` to begin a feature specification.

Maison Éclat is a concept experience; no purchases are processed.
