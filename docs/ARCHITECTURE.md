# Architecture

Next.js App Router/React 19/strict TypeScript. Server components own metadata, static routes and content. Client islands own menu, notes and variant selection. Tailwind 4 plus semantic CSS tokens. Self-hosted fonts; no runtime asset CDN.

`src/data/fragrances.ts` is the typed product source. `src/components/sections` renders six semantic chapters. A context shares selection. `ScrollDirector` mutates a stable scene target using one GSAP context/ScrollTrigger; R3F interpolates refs without per-frame React rerenders. One lazy canvas is kept mounted on home; sections occlude or expose it through deliberate stage windows. Product routes use a separate demand-rendered inspector. Static content exists in the server-rendered DOM.

Scene quality uses viewport/prefers-reduced-motion/WebGL feature detection. Mobile DPR 1, desktop capped at 1.5. No heavy postprocessing, remote HDRI or external model decoder. Original Blender-exported hollow glass geometry, local label textures and generated room lighting. Per-instance materials and cloned label textures are disposed on unmount; the single immutable GLTF/label source set stays in the loader cache for route reuse. All three labels load together so selecting a fragrance does not suspend the scene. Context loss and React render errors expose static posters. Buttons provide non-drag rotation/reset.

The browser uses physical glass and a standard-material inner liquid to avoid Three.js's nested-transmission rendering limitation. The active static posters are captured from the browser's own GLB, materials, lighting and initial pose; offline Cycles renders remain an authored source reference. `ScrollDirector` fits the model to each animated window (including image aspect ratio and padding), changes chapter poses, and emits invalidation events. It initializes the target before the canvas is ready. The Hero bottle lifts and fades before the ivory chapter; Origin presents one framed, gently moving still. Composition returns to WebGL for the cap reveal. At each later shot boundary, the shared canvas fades out, switches its target while hidden, and fades into the next chapter. Only posters belonging to animated windows hide when the canvas is ready. R3F demand mode stops frames once interpolation settles. Product drag uses `touch-action: pan-y`, bounded horizontal angle and controls; normal vertical page scrolling stays available.

Verification: Vitest/Testing Library for selection/notes/content invariants, Playwright for actual routes, controls, keyboard, fallback/reduced motion and axe. Production smoke and lab measurements are separate from nondeterministic WebGL screenshots. No pixel-perfect assertions on GPU output.

## Scroll narrative upgrade

`story-choreography.ts` maps clamped chapter progress to reversible rotation, scale and cap separation. Desktop holds are bounded: 170svh for the encounter, 185svh for the gallery. Widths below 900px and heights below 601px use natural flow; reduced motion removes holds and WebGL. The gallery's continuous phase positions three cached original models on a depth/scale orbit, while only discrete selection changes update React context. Buttons and completed drags seek the same native scroll interval. No wheel interception occurs.

`BottleModel` reparents the original cap/seam/brush meshes into a cap assembly and interpolates its lift on demand. Scene lighting follows the active poster window. All home-canvas descendants ignore pointer events, including R3F's inline wrapper; the semantic DOM gallery handles drag, keyboard and buttons. Explicit invalidation accompanies ref/material mutations, and frames stop once poses settle. The home notes state adds composition pose/emphasis without hiding equivalent text.
