# Maison Éclat product requirements

Original fictional fragrance house; local concept experience, no purchases processed.

Visual explorers follow six chapters: Encounter → Origin → Composition → Collection → Ritual → Invitation. Product browsers select Obsidian No. 01, Neroli No. 02 or Santal No. 03 and open a direct-linkable detail route with inspectable bottle and note composition. Keyboard, mobile, reduced-motion and WebGL-disabled users receive equivalent content and controls.

Required routes: `/`, `/fragrances/obsidian-01`, `/fragrances/neroli-02`, `/fragrances/santal-03`, useful 404. One persistent lazy home canvas, static posters, accessible navigation/menu, notes, selector, original identity/metadata. No checkout, accounts, inventory, analytics, forms, CMS or database.

Acceptance: all plan functional scenarios, responsive screenshot review (375/768/1024/1440/1920), keyboard and reduced-motion checks, WebGL failure recovery, automated axe, lint/typecheck/unit/E2E/build actually executed. Performance reports distinguish local lab measurements from field CWV.
